# 测试计划

> 本文为 `test-plan-en.md` 的中文对照版，以英文版为准。
> 同步于：2026-11-03

> 维护人：@IkeaFyj · 重审时机：指标或验收项变化时

## 一、范围与层级

| 层级 | 覆盖内容 | 工具 | 频率 |
|---|---|---|---|
| 单元 | 质量评分、坐标换算、阈值判断 | `pytest` | 每次提交 |
| 接口 | 响应封装、错误码、权限、分页 | `pytest` + `httpx` | 每个 PR |
| 端到端 | 采集 → 识别 → 复核 → 报告 | 手工脚本 | 每周 |
| 模型 | mAP、分类别召回、计数偏差 | `scripts/evaluate.py` | 每个模型版本 |

覆盖率不作为目标。规则更简单：**任何可能悄悄算错数的分支都必须有测试。** 也就是质量评分、
坐标换算、去重与统计——不是 CRUD 接口。

## 二、数据集与划分

| 角色 | 来源 | 规模 | 用途 |
|---|---|---|---|
| 训练 | 公开水下数据集 | ≥ 3000 张 | 拟合 |
| 验证 | 从训练集切出 | 10–15% | 选轮次与阈值 |
| **测试** | 独立切分并冻结 | ≥ 500 张 | 只用于报告指标 |
| 演示 | 水箱自采 | 200–400 帧 | 现场演示与 E4 微调 |

**按视频或会话划分，绝不按帧划分。** 相邻帧几乎重复，随机按帧划分会把 mAP 抬高一大截。
划分后跑一遍感知哈希，剔除与训练集视觉重复的测试图。

测试集一旦冻结就不再改动。清单 `test-manifest.txt`（每行“文件名 md5”）进仓库，图片本身不进。

## 三、指标与验收

| 编号 | 指标 | 目标 | 测量口径 |
|---|---|---|---|
| AL-01 | mAP@0.5，四类物种 | ≥ 0.75 | 冻结测试集 |
| AL-02 | mAP@0.5:0.95 | ≥ 0.45 | 冻结测试集 |
| AL-03 | 分类别召回 | 四类均 ≥ 0.75 | 冻结测试集 |
| AL-04 | 相对基线提升 | mAP@0.5 +0.03 | 同数据、同轮次、同种子 |
| AL-05 | 推理速度 | ≥ 基线 90% | 同硬件测 100 张 |
| AL-06 | 参数量增幅 | ≤ 20% | 模型 summary |
| AL-07 | 计数偏差 | ≤ 15% | 三段 3 分钟视频人工对照 |

在 500 张测试集上，+0.03 的差距接近随机波动。基线模型与改进模型各跑三个随机种子，报均值 ± 标准差。

## 四、测试数据与夹具

- `tests/fixtures/` 放三张小图（清晰、模糊、过曝各一）与一份录好的识别结果，总量控制在 200 KB 内，进仓库。
- 任何测试都不许打开真实摄像头，采集通过夹具返回预置帧。
- 需要数据库的测试用临时 SQLite 文件，每个会话建一次、删一次。

## 五、工具与命令

```
ruff check .            # 静态检查
ruff format --check .   # 格式检查
pytest -q               # 全部测试
python scripts/evaluate.py --weights data/models/<版本>/best.pt --split test
python scripts/check-bilingual.py
```

模型评估打印一张表，同时把 `metrics.json` 写到权重旁边，保证“版本”与“数字”不分离。

## 六、缺陷处理

| 级别 | 含义 | 规则 |
|---|---|---|
| 阻塞 | 系统不可用、数据丢失、指标未达标 | 提交前必须清零 |
| 严重 | 核心链路阻断、权限绕过 | 提交前必须清零 |
| 一般 | 界面与体验问题 | 遗留不超过 5 个，逐个登记负责人 |

模型指标未达标属于阻塞级。调低阈值让它“通过”不是修复，实验记录里必须写清试过什么。
