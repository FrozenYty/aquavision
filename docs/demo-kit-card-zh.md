# 演示现场用品卡

> 同步于：2026-11-27

> 维护人：@FrozenYty · 重审时机：用品、检查项或布置变化时

一张纸，一支笔，逐项打勾。勾不上的一项，说明这张卡本身也有错：当天就改卡，不要改成记忆。

## 一、出发前

- [ ] **笔记本**——充满电，装着演示用的那份检出。
- [ ] **离线数据库副本**——runbook 第 5 节用 `VACUUM INTO` 写出的一致副本，连同采集帧目录。
- [ ] **索引 1 的摄像头**——USB 摄像头，不是笔记本内置那个。
- [ ] **台灯**——美的 MT-10T4，USB 供电，调好一档后用胶带封住触摸区。
- [ ] **偏振片**——同一张裁出的两块，都在。
- [ ] **装置（ESP32-S3）**——面板、按键，装在面包板上。
- [ ] **备用 USB 线**——数据线，不是只能充电的那种。
- [ ] **电源**——笔记本电源适配器、台灯的 USB 供电、一个空着的墙插。

## 二、在现场的摆放顺序

1. 先找墙插，接上插线板。
2. 摆桌子，鱼缸放在正中。
3. 台灯对着鱼缸打光；一块偏振片平贴灯头。
4. 摄像头放在鱼缸前面，装上镜头侧那块偏振片。
5. 装置放在鱼缸左边，按键朝向演示的人，USB 线够得着。
6. 笔记本放在右边，摄像头的线走到它这里。
7. 备用 USB 线用胶带粘在桌沿，不要留在包里。
8. 离线数据库副本放在笔记本上，第一帧之前恢复好。

## 三、到场检查

- [ ] 摄像头从索引 1 打开：`python scripts/test_exposure.py --index 1` 退出码 0。
- [ ] 离线数据库副本就是 runbook 第 5 节用 `VACUUM INTO` 写出的那份，帧目录在旁边：`/api/health` 有应答，并且能打开一帧。
- [ ] 电源：台灯走 USB，不用电池；所有插头都在插线板上，还留一个空位。
- [ ] 线：摄像头线插到位、不绷紧；装置的 USB 线与备用线都够得着。
- [ ] 这张卡在桌上，打印成一页——不是在手机上看的。

## 四、第一次彩排

- [ ] 第一次彩排只拿这张卡跑——不靠记忆，不靠第二张清单，不问人。
- [ ] 做一项勾一项；勾不上的一项，就是当天第一个缺陷。
- [ ] 结束时在卡上签名并写日期；签了名的卡，就是 P4-18 完成的证据。
